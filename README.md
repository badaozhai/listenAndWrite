# 听写助手

给小学生用的安卓听写。语文和英语分开。词在手机里读出来，人在本子上写。读的时候不用看屏幕。

语音是手机系统实时合成的，没有预存的录音。

## 使用

打开后先选语文或英语。上次听过的课或单元会留在首页，点一下就能继续。

语文按课听写。有词的课会讲易混字，例如「势」不是「事情」的「事」。普通词和四字词语的书写时间可以在设置里改。

英语分成两块，互不覆盖：

- **认读**走单词表。会报出英文，用来认单词。报法可以是只报英文、只报中文，或中英都报。
- **默写**是五上第 1 到 4 单元的练习。默认只报中文，在纸上写英文，播放时不显示答案。这个报法不改单词表的设置。

两种播放：

- **定时**。读完有一声「嘀」，然后倒计时。时间到了自动读下一题。英语按字母数留时间，短词用最少秒数。
- **说完再继续**。写好了说「下一个」或「好了」，也可以点大按钮。

写错的词可以放进错题本。错题本按科目分开，可以自己加、改、删。

听写结束可以对照本子点「写错了」，也可以拍照批改。

## 词库

数据在第一次打开该科目时写入本地数据库。已经有的不覆盖，改过的意思会留下来。

| 内容 | 范围 | 条数 |
| --- | --- | --- |
| 语文词语 | 五年级上册有词的课，外加两处语文园地 | 213 |
| 英语单词 | 第 1 到 8 单元 | 164 |
| 英语默写 | 第 1 到 4 单元 | 120 |

语文首页按课排列，没有词的课是空的。英语单词表是 15 个单元，第 9 单元以后是空的。同一个英文如果在不同单元意思不同，会各留一条，例如「listen」听和听从。

语文第 4 课的「地道」是地下通道，不是「地道的北京话」。

默写第 3 单元的短语页没有印红色答案，是按本单元词表补的，列表里写了「没有印答案」。不对可以点进单元改。

## 拍照批改

只批这次听写的词。卷子上最好写上 1、2、3。逐字看，不看笔顺。

- **写对**。认出来就是要写的那个字。字写得歪，只要字对，不算错。
- **明确写错**。认成了另一个字，例如「势」写成「事」，「己」写成「已」。这个词直接进错题本。识别看错了可以点「算对」撤出。
- **笔画没到位**（英文是**没认清**）。少字、多字，或者这个字把握很低。写出的字和正字并排，点「写错了」才进错题本。
- **没找到**。卷子上没有对上这一行。

英文按字母逐个对，忽略大小写、空格和标点。长度不一样算没认清，不用整词编辑距离。

## 代码

包名 `app.listenandwrite`。界面是 Jetpack Compose，词存在 Room，设置在 DataStore。

| 目录 | 内容 |
| --- | --- |
| `domain` | 播放稿、计时、易混字、批改判定、上次播放 |
| `data` | 数据库、语文词表、英语单词、默写练习、错题本 |
| `speech` | 系统朗读，以及「下一个」「好了」 |
| `ocr` | 离线中文文字识别，以及卷子上的字框 |
| `ui` | 选科、认读、默写、播放、对答案、批改、错题本、设置 |

批改判定在 `domain/GradeSheet.kt`。播放时说什么在 `domain/LessonScript.kt`。

## 构建和测试

需要 JDK 17。Android SDK 路径写在本机的 `local.properties` 里，这个文件不提交。`minSdk` 26，`compileSdk` 35。

```bash
./gradlew testDebugUnitTest
./gradlew assembleDebug
```

调试包在 `app/build/outputs/apk/debug/app-debug.apk`。

单元测试覆盖词表条数、播放计时、易混字、批改判定，以及下面的手写样本。`app/src/androidTest` 里有一份把三张中文手写交给真机识别的探测，不作为日常门禁。

## 手写样本

测试资源里的图是生成的墨迹，用来驱动批改规则，不是手机摄像头认出来的结果。

| 目录 | 内容 |
| --- | --- |
| `app/src/test/resources/chinese-chars` | 语文词表里 420 个字。每个字有正字和不规范两种。能对上易混字的还有一张错字 |
| `app/src/test/resources/english-hands` | 英语 284 条收成 253 个拼写。每个拼写有印刷体、手写体、断笔、错一个字母 |
| `app/src/test/resources/handwriting` | 最早的三张对照：己写成已、未的笔画残缺、写对的己 |

目录里的 `catalog.tsv` 或 `readings.tsv` 写着每张图对应的词和识别结果。测试读这些标注，调用 `gradeOne`，不在单元测试里跑识别器。
